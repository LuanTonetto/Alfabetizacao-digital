Como Usar Email

O que é Email?

Email (ou correio eletrônico) é uma forma de enviar mensagens pela internet. É como enviar uma carta, mas instantaneamente!

Criando sua conta de email

Passo 1: Abra o navegador

Clique no ícone do navegador (Chrome, Firefox, Edge, etc.)

Passo 2: Vá para o Gmail

Digite na barra de endereço: www.gmail.com

Passo 3: Clique em "Criar Conta"

Procure pelo botão "Criar conta" ou "Sign up"

Passo 4: Preencha os dados

Digite seu nome, escolha um nome de usuário (seu email) e uma senha segura

Enviando um email

1. Clique em "Escrever"

Procure este botão no lado esquerdo da tela

2. Preencha os campos

Para: endereço de quem vai receber
Assunto: o tema do email
Mensagem: o que você quer dizer

3. Clique em "Enviar"

Seu email será entregue em segundos!

💡 Dica importante: Nunca compartilhe sua senha com ninguém. Nem mesmo amigos ou familiares!

Como Buscar na Internet

O que é um buscador?

Um buscador é uma ferramenta que ajuda a encontrar informações na internet. O mais conhecido é o Google.

Passo a passo para buscar

Passo 1: Abra um buscador

Digite na barra do navegador: www.google.com.br

Passo 2: Clique na caixa de busca

A caixa de busca é o retângulo branco no meio da página

Passo 3: Digite o que você procura

Por exemplo: "receita de bolo", "endereço da prefeitura", "como cuidar de plantas"

Passo 4: Pressione ENTER ou clique no botão de busca

A página mostrará vários resultados com informações relacionadas

Dicas para buscas melhores

✓ Use palavras simples e claras

✓ Se não encontrar, tente outras palavras

✓ Leia o título dos resultados primeiro

✓ Se a página abrir estranho, volte atrás e tente outro resultado

⚠️ Atenção: Nem todos os sites que aparecem são seguros. Se algo parecer estranho ou pedir dados pessoais sem motivo, não clique.

5 Dicas Importantes de Segurança

1. Proteja sua senha

✓ Use senhas com letras, números e símbolos
✓ Não use datas de nascimento ou nomes
✓ Não conte sua senha para ninguém
✓ Use senhas diferentes para contas diferentes

2. Cuidado com emails estranhos

✓ Não clique em links de emails desconhecidos
✓ Não baixe anexos de pessoas que não conhece
✓ Bancos nunca pedem sua senha por email
✓ Desconfie de ofertas muito boas para ser verdade

3. Cuidado com o que você compartilha

✓ Não compartilhe seu CPF ou RG online
✓ Não divulgue seu telefone em sites desconhecidos
✓ Pense bem antes de compartilhar fotos
✓ Não use a mesma foto de perfil em vários lugares

4. Verifique os sites antes de usar

✓ Sites legítimos começam com "https://" (note o "s")
✓ Procure por um cadeado 🔒 na barra de endereços
✓ Quando em dúvida, busque o site pelo Google
✓ Leia as avaliações de outros usuários

5. Atualize seus programas

✓ Sempre aceite as atualizações do seu navegador
✓ Mantenha seu sistema operacional atualizado
✓ Use um antivírus (muitos são gratuitos)
✓ Faça scans regularmente

⚠️ Se algo ruim acontecer:
Se você acha que foi enganado na internet, não tenha vergonha. Procure ajuda de alguém de confiança ou denuncie em www.safernet.org.br

Glossário - Palavras Técnicas Explicadas

Aqui estão palavras que você pode ouvir ao usar a internet, explicadas de forma simples:

Navegador: É o programa que você usa para acessar a internet (Chrome, Firefox, Edge, Safari)
Website/Site: É uma página ou conjunto de páginas na internet. Como um estabelecimento online.
URL: O endereço de um site (exemplo: www.google.com.br). É escrito na barra de endereços.
Login: É quando você entra em uma conta digitando seu usuário e senha.
Download: Baixar um arquivo de internet para seu computador.
Upload: Enviar um arquivo do seu computador para a internet.
Cookie: Um pequeno arquivo que sites salvam no seu computador. Geralmente torna a experiência mais fácil.
Vírus/Malware: Programas ruins que danificam seu computador. Se proteja usando antivírus.
Firewall: Uma proteção que controla o que entra e sai do seu computador.
Senha/Password: Código secreto que você cria para proteger suas contas.
WiFi/Internet: Conexão sem fio que permite usar a internet.
Email: Também chamado de correio eletrônico. Serviço para enviar mensagens pela internet.
Hyperlink/Link: Um texto ou imagem que você clica para ir para outro site.
Ícone: Uma pequena imagem que representa um programa ou ação.
Buscador/Search Engine: Ferramenta para procurar informações na internet (Google, Bing, etc).
